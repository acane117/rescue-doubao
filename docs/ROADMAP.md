# 后续优化方向

以下是供协作者讨论的候选项，并非已经实现或承诺完成的功能。

| 方向 | 当前情况 | 可验收的改进 |
| --- | --- | --- |
| 跨网联机 | 公共 PeerJS 信令，未配置 TURN | 两台真实设备跨运营商完成建房、开战、技能与失败同步；受限 NAT 有明确提示或中继方案 |
| 断线恢复 | 房主离开即结束，不支持中途加入 | 设计带会话/输入序号的重连协议，验证旧输入不能重复执行 |
| 手机操作 | 16:9 横屏与旋转输入已实现 | 在真实 iOS/Android 浏览器验证全屏、方向锁定、刘海安全区和多点触控 |
| 动画与性能 | 距离驱动八帧步态、镜头活动区和绘制缓存 | 在明确设备/浏览器上测帧时间、内存和网络积压，不以模型计算耗时替代整体 FPS |
| 可维护性 | 原战斗与声音提取模块仍压缩 | 在保留来源与行为回归的前提下逐步整理，避免一次性重写改变原 AI |
| 素材与许可 | 原作者与原资源许可未核实 | 补齐权利人和许可依据，或替换为有明确授权的独立美术和音轨 |

当前数值和限制见 README；更改平衡参数时提供 1–4 人对照结果。
