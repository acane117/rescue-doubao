# 开发与验证记录

以下来自当前工程的开发记录；早期条目的测试数量对应当时版本。

## 已实现

### 0.5 手机横屏

- 手机对局固定使用 16:9 横向画面；竖持时自动旋转整个战斗界面，横持时恢复正常横向排布，不再挤成窄小画面。
- 对支持相关 API 的触屏浏览器，在开始对局时尝试全屏并锁定横屏；不支持系统方向锁定的浏览器仍使用横向布局。
- 手机摇杆与技能按钮重新排布、放大，摇杆输入按画面旋转做逆变换。画布按旋转前的实际尺寸建立缓冲，保持比例和清晰度。
- 45 项测试通过，覆盖竖屏/横屏尺寸等价、平板与桌面区别、旋转后的摇杆方向。另在 390×844 和 844×390 浏览器视口验证画面及触控布局。

### 0.4 名称与原版音频

- 游戏改名为“营救豆包”，同步更新网页标题、大厅品牌、分享摘要、复制邀请文案及通关文字，保留原分享网址。
- 恢复原网页的全部 8 个 MP3：普通背景音乐、死亡背景音乐、大笑、超级大笑、奶蛋完整语音、刀盾狗叫声，以及企鹅狂暴与死亡音轨。来源清单见 `art/original-audio-sources.json`，本地文件位于 `dist/assets/audio/`。
- `dist/audio-original.js` 保留原游戏的声音控制器和 Web Audio 合成参数，恢复射击、命中、受伤、防御、冲撞、铃声、冰冻、爆炸与 Boss 招式等音效。
- `dist/audio.js` 将合作模式的事件与角色状态接入原声音模块。同一事件不会因重复快照多次播放，每个企鹅和玩家奶蛋拥有独立音轨状态；队友收到原技能序列的时间位置。
- 点击创建房间、加入或单人练习时解锁浏览器音频。大厅与战斗右上角提供声音开关，并记住静音选择；暂停、切后台和离开会停止相应声音。
- 42 项测试通过；本地浏览器确认普通背景音乐播放进度持续前进、静音停止、恢复后继续，以及奶蛋原音轨加载播放。

### 0.3 动画与拖影修复

- 奶蛙改用八帧交替迈腿动画，按实际移动距离推进；停止输入就恢复站姿，受阻时不再原地滑步。高刷新率屏幕的重复物理帧会保持当前步态。
- 新建无外圈光晕的高清角色素材，保留立体卡通画风；行走图集为 `dist/assets/characters/hero-walk-v3.png`，站立、大笑、防御图集为 `dist/assets/characters/hero-poses-v3.png`。使用内置 imagegen 生成，提示及脚底对齐参数见 `art/hero-motion-v3-prompts.txt`。
- 去掉额外的身体上下浮动、左右倾斜和缩放。镜头保留中间活动区域，只有越界才平移，停步后立即稳定。
- 每帧以完全不透明的背景覆盖整张物理画布，清除残留透明度、滤镜和混合状态。队友插值到最后确认位置为止，不再超前后反向修正；收到新快照时从当前显示位置继续。
- 34 项测试通过，新增完整步态、脚底对齐、高刷新率、停步、受阻、镜头稳定、绘制状态重置及远端插值覆盖。本地浏览器实测持续右移与停步，角色素材正常加载，未记录控制台错误。

### 0.2 更新

- 大厅改为明亮的奶油色与浅紫色布局，战斗 HUD 改为圆角卡片与技能栏。
- 用内置 imagegen 工具依据原角色生成 `dist/assets/characters/hero-hd.png` 高清四姿态透明图集；生成提示见 `art/hero-hd-prompt.txt`。角色保持黄色身体、绿色眼睛、奶油肚皮和原立体卡通质感。
- 画布根据屏幕尺寸与设备像素比建立清晰的绘制缓冲区，同时限制像素预算。缓存子弹光效与文字图层，减少逐帧模糊阴影计算。
- 物理以固定 60Hz 步长运行，房主直接渲染实时状态。队友使用移动预测与状态插值。按键立即送入操作队列，特效按事件增量传输，状态发送积压时丢弃过时画面。
- 友方奶球造成正常伤害的 50%，会被前方队友挡住；防御、无敌时间和倒地救援规则仍有效。
- 地图宽高各扩大 50%，逻辑世界为 1920×1080；本机镜头跟随自己的角色，并显示小地图。
- 在同一台机器的 Node 压力测试中，4 人、40 只怪物蓄力场景的攻击判定平均每帧从约 12.27ms 降至约 0.06ms。该数据是特定计算场景的耗时，不代表整体帧率或所有设备的表现。
- 25 项测试通过，新增友伤、阻挡、扩大地图、镜头边界、画布分辨率预算与增量特效传输覆盖。

### 原有合作功能

- 6 位房间码、邀请链接、玩家昵称、准备状态及房主开始。
- 浏览器之间通过 WebRTC 数据通道同步；房主运行战斗逻辑，队友发送操作。
- 复用七章关卡、原角色图、场景图、普通敌人和四种 Boss 的原有战斗逻辑。
- 每波小怪总量 = 原数量 × 本关开始时的在线人数；同屏上限和出怪速度同步调整。普通小怪血量不因人数增加。
- 四种 Boss 血量 = 原血量 × 70% × 本关人数；攻击伤害 = 原伤害 × 75%；预警及收招时间延长约 25%。部分原有独立招式计时仍由原 AI 控制。
- 每位玩家独立移动、生命、防御、冲撞次数、能量、罐头和奶蛋状态。
- 靠近倒下的队友并按住救援 3 秒，恢复其 60 点生命；下一章开始时倒下的队友也会恢复。
- 强化由房主选择，对全队生效。全队倒下后可以免费重试本关。
- 电脑键盘、手机虚拟摇杆与触控按钮。

## 启动

需要 Node.js 20 或更新版本，无须安装依赖。

```sh
npm start
```

打开 http://localhost:4173 。同一局域网中的其他设备可以打开房主电脑的局域网地址加 `:4173`；远程朋友需要访问部署后的 HTTPS 网站。电脑必须允许该预览端口的入站连接。不要直接双击 HTML，浏览器会限制 ES 模块加载。

## 操作

WASD / 方向键移动；按住 F 连续发射奶球；按住空格防御；Shift 冲撞；E 大笑；C 罐头；V 奶蛋；H 扶起队友；J 跳跃；Escape 暂停。最终战 Q 讲笑话，蓄满后再按 Q，连按 R 维持大笑。

## 修改位置

- `dist/coop.js`：`BALANCE` 为 Boss 削弱比例，`progressWaves` 为人数倍率，`stepPlayers` 为多人状态，`stepEnemy` 为敌人索敌与多人攻击判定。
- `dist/network.js`：房间码、PeerJS 连接、最多 4 人限制、输入校验及状态广播。
- `dist/app.js`：大厅、操作输入、HUD、强化与失败界面。
- `dist/render.js`：画布渲染，使用 `dist/assets/` 中的原画面素材。
- `dist/style.css`：大厅与手机布局。

## 当前试玩边界

- 房主离开会结束本局，暂不支持房主迁移、战斗中加入或断线恢复。房主切后台时战斗暂停。
- 使用 PeerJS 公共信令服务；严格 NAT 或限制 WebRTC 的网络可能无法直连。本版未配置 TURN 中继。可后续在 `RoomNetwork.open` 中配置自有 PeerServer 与 TURN 服务。
- 人数在每章开始时锁定，玩家中途离开不立即改变本章怪物血量、数量；下一章按剩余在线人数调整。
- 保留原美术、背景音乐和技能音效并重做画布渲染，原结局视频和部分复杂特效暂未迁移；此版本适合先验证合作玩法与数值。
